# Insurance Cost Analysis (Python)

## Description
This project explores **insurance charges** and identifies the key factors that influence cost (e.g., age, BMI, smoking status). The analysis focuses on clean, explainable insights using Python-based exploratory data analysis.

## Tech Stack
- Python
- Pandas, NumPy
- Matplotlib / Seaborn (for visualizations)
- Jupyter Notebook

## What I did
- Cleaned and prepared the dataset for analysis (missing values, types, basic validation)
- Performed exploratory analysis to understand distributions and relationships
- Visualized how different factors impact insurance charges
- Summarized insights that can help pricing and risk understanding
